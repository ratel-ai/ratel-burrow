# examples

Small agents that write a Burrow dir (`./.ratel/burrow`) so every screen has data.

- `ts-sdk/`: a scripted support-desk agent on `@ratel-ai/sdk` with adaptive ranking on.
  `pnpm --filter @ratel-ai/burrow-example-ts-sdk start` (add `-- --live` to keep it running),
  then run `ratel-burrow` from `examples/ts-sdk`.
